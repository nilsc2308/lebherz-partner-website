# Lebherz & Partner GmbH – Website (Apple-Stil)

Statischer Mehrseiter ohne Build-Schritt. Einfach den Ordner auf einen Webspace laden (oder Netlify/GitHub Pages).

- `index.html` … alle Seiten, `styles.css`, `main.js`
- `img/` Fotos (WebP, zwei Größen), `img/BILDNACHWEIS.md`
- `fonts/` Inter (lokal)
- `netlify.toml` Security-Header + 404
- `LAUNCH-CHECKLISTE.md` offene Kundenangaben

Lokal ansehen: `python3 -m http.server 8765` im Projektordner, dann http://localhost:8765
